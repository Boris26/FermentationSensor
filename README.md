# FermentationSensor

Firmware für einen WLAN-fähigen Gärsensor auf Basis des Arduino Nano 33 IoT.

Geplant sind:
- Bier- und Umgebungstemperatur über DS18B20
- Gäraktivität über einen Differenzdrucksensor
- lokaler Pause-Taster für die Blubb-Messung
- Status-LED
- WLAN-Anbindung an BeerDataStore
- spätere lokale WLAN-Ersteinrichtung ohne Zugangsdaten im Repository

## Aktueller Stand

Das Grundgerüst und die Temperaturmessung mit bis zu zwei DS18B20-Sensoren sind vorbereitet.
